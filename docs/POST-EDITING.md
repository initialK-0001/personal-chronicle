# 投稿の削除と編集画面

2026-11-16 実装済み 本番反映・操作確認済み

- 通常投稿と作品紹介の編集画面は `/admin?edit=投稿ID` の通常ページ
- 新規作成ボタンでサーバーに下書きを作成してから固有URLへ遷移 再読み込みは同じ下書きを開く
- 下書きはサーバーに自動保存 保存して一覧へで保存完了後に戻る 未保存・画像送信中の離脱は警告
- 一覧・投稿詳細・編集画面の削除はゴミ箱へ移動 公開版と下書き・画像・コメント・日時・関連指定を保持
- `chronicle_posts.visibility=trash` は通常の管理一覧と公開一覧・記事・検索・作品集・サイトマップから除外
- 他の公開投稿から参照されない画像は公開APIからも404
- 削除済み投稿への遅延保存・公開・非公開操作は409 改訂番号による競合検出を維持
- ゴミ箱の戻すは必ず非公開 復元時の自動公開なし 再公開は本人の操作が必要
- 親作品を削除しても別の投稿であるバージョンや関連投稿は削除しない 公開済みの子投稿は通常投稿として維持 公開画面から親への関連表示のみ消える
- バックアップ形式4の既存列でゴミ箱を復元可能 スキーマ変更なし 完全削除・画像の物理削除なし
- 旧WordPress記事は別の旧記事編集画面と非公開化を継続 今回の削除対象はchronicle_postsの投稿と下書き
- プレビューとリンク入力の補助ダイアログは維持 投稿編集本体のポップアップは廃止
