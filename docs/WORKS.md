# 作品紹介と通常投稿

2026-11-16 更新 現行仕様

## 投稿の単位
作品全体の紹介も各バージョンの紹介も chronicle_posts の通常投稿
紹介本文・画像・タイトル・日時・公開状態・コメントは投稿に一度だけ保存する
公開URLは通常投稿と同じ `/?post={自動採番ID}` 作品集とタイムラインのリンク先は同一

## 操作
- 投稿管理の作品集から「作品紹介を書く」で通常エディタを開く
- 普通に投稿を書いた後からでも「作品との関連」で作品全体の紹介に指定できる
- 作品集の各作品の「バージョンを追加」で親作品を指定済みの通常エディタが開く
- 本文は画像・文章・見出し・リンク・引用を混在できる タイトルは任意
- 通常の自動下書き保存 公開 公開内容を更新 非公開にする を利用
- 作業メモや撮影画像は「関連投稿」にして作品全体またはバージョンへ関連付けられる
- 作品専用の説明文入力欄・公開ボタン・保存APIは廃止

## データ
投稿のdraft_jsonとsnapshot_jsonに任意のwork属性を持つ
- null 通常の投稿
- role=work parent=null 作品全体の紹介
- role=version parent=作品紹介の投稿ID バージョンの紹介
- role=related parent=作品またはバージョンの投稿ID 関連投稿

投稿本文と関連指定は同じrevisionで保存・公開する 下書き変更は公開版へ反映しない
親指定は存在・役割・自己参照を検証 バージョンの下にバージョンは作れない
ポーズタグの投稿は作品との関連指定を拒否するが通常投稿としての保存は可能
タイトルの語句から勝手にポーズを分類しない

## 公開表示
`/works` は公開済みの作品全体紹介を投稿日時順で表示する
`/works/{ID}` は互換経路として公開紹介投稿のURLへ302転送する
個別投稿ページにバージョン一覧・関連投稿・親作品へのリンクを表示する
作品全体には各バージョンの関連投稿もまとめて表示する
関連投稿は公開済み投稿だけを表示 未公開の親への参照IDは公開APIから取り除く
親作品が非公開のとき子への作品集リンクは表示しない
ただし子自身が公開済みなら通常投稿としてタイムラインと投稿URLからは読める
子も隠す場合はその投稿を非公開にする

## 管理と互換
`/admin/works` は `/admin?view=works` へ転送 管理も通常投稿の絞り込み
旧作品管理API・専用エディタは廃止
chronicle_worksテーブルは旧バックアップの復元互換のため残す 新規の読み書きはしない
バックアップ形式4を継続 投稿JSONの関連指定を含めて復元 旧形式1/2/3互換を維持
配備時にchronicle_worksが空であることを必ず検証する 空でなければ内容を失わないよう更新を中止
旧WordPress記事編集は別系統のため今回の作品指定は新しい統合エディタの投稿が対象

## 配備・復旧
scripts/deploy-work-posts.php は前版ハッシュを検証して7ファイルを差し替える一回実行CLI
既存記事・下書き・画像・DBテーブルを削除しない
変更前コードはprivate/works-posts-before-20261116/previousへ保全
works-posts-deployment.jsonを確認してCronをOFFに戻す
旧scripts/deploy-works.phpは17:16版の履歴 再実行しない

## 廃止した仕様
17:16版の「作品専用の紹介文と独立した公開状態」は廃止
過去のSTATUS・VERIFICATIONの記録は当時の実装履歴であり現行仕様ではない
