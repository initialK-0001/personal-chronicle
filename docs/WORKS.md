# 作品集とバージョン

2026-11-16 実装

- 公開一覧 `/works` 個別 `/works/{自動採番ID}` 管理 `/admin/works`
- `chronicle_works` の parent_id がNULLなら作品全体 作品IDならそのバージョン 孫階層なし
- 作品全体と各バージョンが独立した名前・説明・関連投稿IDを持つ
- draft_jsonとsnapshot_jsonを分離 下書き保存では公開内容を変えない 公開ボタンで確定
- 管理者認証・同一Origin・CSRF必須 revisionによる同時編集競合拒否
- 親作品が非公開なら子バージョンも公開APIと直接URLから見えない 再公開すると公開済みの子も再表示
- 関連投稿は公開済み投稿だけを表示 非公開化が即時反映 IDも公開APIから除外
- 作品全体ページは自身と公開バージョンの関連投稿を重複なしの投稿日時順で表示
- ポーズは作品として自動登録しない タイトルまたはテーマにポーズ/poseが含まれる投稿は候補と公開表示から除外
- 既存投稿を自動で作品・バージョンへ変換しない Karenの説明やバージョン名を生成しない
- 管理画面から作品を追加してサーバーへ下書き保存 その作品を開きバージョンを追加
- 説明はプレーンテキスト 改行維持 HTMLは表示時エスケープ 画像は関連投稿として表示
- 管理画面は明示的な下書き保存 未保存の画面移動とページ離脱に警告 端末保存なし
- バックアップ形式4に作品・バージョン・関連付けを含む 旧形式1/2/3は空の作品テーブルとして復元
