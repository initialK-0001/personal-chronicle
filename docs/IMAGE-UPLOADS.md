# 画像アップロードの現行仕様

2026-11-16 利用者指定により変更

- 画像1枚30MBまで（30 × 1024 × 1024 bytes）
- 幅4000ピクセル以下 かつ 高さ4000ピクセル以下
- JPEG PNG WebP 透過PNG対応 向き補正後も原寸を維持 自動縮小なし
- 旧「画像1枚8MB」「1投稿合計30MB」は廃止
- 複数画像は1枚ずつ順番に送信 保存先はエックスサーバーの非公開画像フォルダー
- 通常投稿と旧記事編集に同じ上限を適用
- APIで容量と各辺を再検証 上限超過は理由を表示して拒否
- 画像の再保存・メタデータ除去と公開参照による画像配信制御を維持
- 入力の形式・画素数を検証してからGDで展開 既存のメモリ予測による拒否も維持
- 認証済み画像アップロード処理のみPHPメモリ上限を最低512MBへ設定 実際に512MBを常時確保する意味ではない
- Web側post_max_sizeは最低32M upload_max_filesizeは最低30Mを確保 既存の大きい設定は維持
- 更新時にPHP設定とコードを非公開領域へ保全 既存画像の変換や投稿の公開はしない
